# Vertical & Horizontal auto scaling
- Vert: Adding more resouces to the underlying machine.
- Horiz: Adding more servers in totoal.

## Scaling Cluster Infra ( Horizontal Scaling )
- Creating more pods.

## Scaling Workloads
- Increasing resources on a given node.
